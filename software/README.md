# AZRAS System v1.0.0 — Initial Public Release

This is the first public release of the AZRAS System.

AZRAS was originally developed to evaluate the RC Upright Method, a construction method patented in Japan approximately 20 years ago and used to construct three actual buildings.

The RC Upright Method uses 300 mm-thick unidirectional reinforced-concrete walls as a long-life structural core. In the AZRAS concept, this RC core is evaluated on the basis of a 200-year long-term service-life scenario, while replaceable building components are separated into Infill and Outfill.

AZRAS has since evolved beyond the evaluation of a single construction method.

It can now be used to compare different construction methods under equivalent project conditions, including different regions and climates.

## Main Evaluation Areas

The AZRAS System includes tools for evaluating:

- CO2 emissions and environmental performance
- Energy consumption and regional 8760-hour analysis
- Construction cost
- Long-term economic performance
- Investment and business feasibility
- Disaster and hazard risk
- Long-term building information management
- Digital Twin applications

They allow users to examine how different construction methods can be compared under substantially equivalent planning conditions.

## Drawing Input

The standard workflow uses detailed architectural drawings exported directly to PDF from CAD or similar software.

Direct extraction from CAD/DWG/DXF files is not part of the standard workflow.

Scanned image PDFs of paper drawings are generally outside the intended scope.

# 日本語 / Japanese

## AZRAS System v1.0.0 — 初回公開版

AZRAS Systemの初回公開版です。

AZRASは、約20年前に日本で特許を取得し、実際に3棟を建設した「RCアップライト工法」を検証するために開発を開始したシステムです。

RCアップライト工法は、厚さ300mmの一方向RC壁を長寿命の構造コアとして使用します。

AZRASでは、このRCコアを200年間の長期利用を検証対象とし、更新可能な建築部分を「インフィル（Infill）」と「アウトフィル（Outfill）」に分離して考えます。

その後AZRASは、一つの建築工法だけを検証するシステムから発展しました。

現在では、世界の様々な地域・気候条件を含め、異なる建築工法を同等のプロジェクト条件のもとで比較・検証することができます。

## 主な評価項目

AZRAS Systemでは、主に次の項目を評価・比較できます。

- CO2排出量・環境性能
- エネルギー使用量・地域別8760時間解析
- 建設費
- 長期的な経済性
- 投資・事業性
- 災害・ハザードリスク
- 長期的な建物情報管理
- デジタルツイン
